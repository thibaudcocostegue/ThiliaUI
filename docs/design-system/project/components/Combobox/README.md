Liste filtrable à la saisie, où la valeur doit être une option existante, basée sur le Combobox de Reka UI.

Le consommateur fournit le libellé, les options, le filtrage et la valeur.

- Utilisez-le à partir d'une dizaine d'options.
- Prévoyez un message lorsque aucune option ne correspond.
- Pour accepter une saisie libre, préférez Autocomplete.
