Navigation principale, avec panneaux de liens optionnels, basée sur le NavigationMenu de Reka UI.

Le consommateur fournit les liens, l'emplacement actif et les panneaux.

- Signalez la page active par `aria-current` et un soulignement `thilia-accent`.
- Limitez-la à quelques entrées courtes.
- Pour changer de vue dans une même page, préférez Tabs.
