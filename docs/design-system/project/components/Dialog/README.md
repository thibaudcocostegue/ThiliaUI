Fenêtre modale pour une décision ou une courte tâche, basée sur le Dialog de Reka UI.

Le consommateur fournit le titre, le contenu et les actions.

- Conservez le focus piégé, la fermeture par Échap et le retour du focus au déclencheur.
- Posez la surface sur `thilia-scrim`, sans ombre.
- Placez l'action principale à droite.
