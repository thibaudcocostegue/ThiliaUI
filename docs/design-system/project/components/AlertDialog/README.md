Confirmation bloquante avant une action risquée, basée sur l'AlertDialog de Reka UI.

Le consommateur fournit le titre, la conséquence et les deux actions.

- Nommez l'action par son verbe : « Purger », pas « Oui ».
- Placez le focus initial sur « Annuler ».
- Ne fermez pas la fenêtre par un clic à l'extérieur.
