Champ de saisie sur une ligne, avec libellé, aide et état d'erreur.

Le consommateur fournit le libellé, la valeur et, si besoin, l'aide ou le message d'erreur.

- Reliez toujours le libellé au champ.
- Formulez l'erreur en texte et reliez-la au champ : la couleur `thilia-danger` ne suffit pas.
- N'utilisez pas le texte indicatif comme libellé.
