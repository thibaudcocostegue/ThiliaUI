Message temporaire confirmant le résultat d'une action, basé sur le Toast de Reka UI.

Le consommateur fournit le type et le message.

- Affichez toujours l'étiquette du type, pour ne pas dépendre de la couleur.
- Rédigez le message en quelques mots.
- Pour une erreur qui exige une décision, préférez Dialog.
