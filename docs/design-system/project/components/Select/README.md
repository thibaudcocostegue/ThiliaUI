Choix d'une option dans une liste déroulante, basé sur le Select de Reka UI.

Le consommateur fournit le libellé, les options et la valeur.

- Conservez la navigation au clavier de Reka UI.
- Signalez l'option active par `thilia-line` et une coche en `thilia-accent`.
- Pour deux ou trois options toujours visibles, préférez Radio.
