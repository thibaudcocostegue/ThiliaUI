Déclenche une action, avec une seule variante primaire par écran.

Le consommateur fournit le libellé, la variante, la taille et l'action. Composez le libellé en `thilia-label`.

- Utilisez `primary` pour l'action principale, `secondary` pour les autres, `ghost` dans les barres denses et `danger` pour une action destructrice.
- Utilisez la hauteur `thilia-control-md` par défaut.
- N'utilisez pas `danger` sans confirmation si l'action est irréversible.
