Jauge graduée, signature du système, basée sur le Progress de Reka UI.

Le consommateur fournit le libellé, la valeur et le maximum.

- Affichez toujours la valeur en texte à côté de la jauge.
- Gardez des graduations de `thilia-gauge-tick` espacées de `thilia-gauge-gap`.
- Réservez-la aux indicateurs clés : pas plus de quelques jauges par écran.
