Assemblage d'un libellé, d'un contrôle et d'un message, pour construire un formulaire.

Le consommateur fournit les contrôles, les règles de validation et les messages.

- Empilez les champs avec un écart de `thilia-space-16`.
- Affichez l'erreur sous le champ concerné.
- Placez l'action principale à droite, à côté de l'annulation.
