Panneau latéral pour consulter ou modifier un élément sans quitter la page, basé sur le Drawer de Reka UI.

Le consommateur fournit le titre, le contenu et les actions.

- Ouvrez-le à droite, sur une largeur de 360 px par défaut.
- Conservez le focus piégé et la fermeture par Échap.
- Animez-le en 200 ms.
